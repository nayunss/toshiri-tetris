# 토시리 테트리스

초등학생을 위한 테트리스. 공간 감각과 추리 능력을 기르는 것이 목표라, 반응 속도가 아니라 **쌓인 높이**가 난이도를 만들도록 설계했습니다.

React 19 + TypeScript + Vite, 렌더는 `<canvas>` 2D.

## 실행

```sh
npm install
npm run dev      # 개발 서버
npm test         # 코어 로직 테스트 71개
npm run build    # 타입 검사 + 빌드
```

테스트는 Node 22의 네이티브 타입 스트리핑으로 돕니다 — 테스트 프레임워크 의존성이 없습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` | 이동 |
| `↑` | 회전 |
| `↓` | 천천히 내리기 |
| `Space` | 뚝 떨어뜨리기 |
| `C` | 조각 맡기기 |
| `1` `2` `3` | 아이템 |
| `P` | 일시정지 |
| `R` | 다시 하기 |
| `M` | 소리 끄기 |

키보드만으로 전 기능에 닿고, 태블릿 터치도 지원합니다.

## 설계 메모

**첫 레벨업이 30~60초 안에 오도록** 점수를 잘게 나눴습니다. 조각 하나 놓을 때마다 +10점, 100점마다 레벨업. 드롭 점수와 콤보는 없습니다 — 있으면 스페이스 연타가 곧 레벨이 되고, 아이가 점수의 출처를 못 읽습니다. 이 요구는 표준 템포에서 실제로 30~60초인지 검사하는 테스트로 고정돼 있습니다.

**속도는 레벨 16에서 362ms로 멈춥니다.** 락딜레이 500ms보다 짧아 최고 속도에서도 마지막 조정 기회가 남습니다. 그 뒤로는 속도가 아니라 쌓인 높이가 난이도를 만듭니다.

**아이템 5종이 레벨마다 순환합니다**(긴막대 · 네모 · 바닥청소 · 없음 · 폭탄). 4레벨에 일부러 아무것도 주지 않아 기대감을 만듭니다. 아이템을 다 쓰면 레벨당 한 번 긴막대를 부를 수 있습니다. 폭탄은 부를 수 없습니다 — 부를 수 있으면 폭탄 → 레벨업 → 폭탄 연쇄로 난이도 곡선이 무너집니다.

## 접근성

- 상태 변화는 `aria-live`로 알립니다. **막힌 조작도 침묵하지 않습니다** — 반응이 없으면 아이는 "안 된다"가 아니라 "고장났다"로 읽습니다
- 블록과 배경의 명도 대비 3:1 이상, 글자는 4.5:1 이상. 블록끼리는 대비비가 아니라 **색상환 각도 25° 이상**으로 구분합니다(휘도가 비슷해도 색상이 멀면 구분되므로)
- `prefers-reduced-motion`에서 **연출만 끄고 게임 규칙은 그대로**입니다. 레벨업 900ms 정지는 규칙이라 유지되고, 떨어지는 조각의 외곽선도 연출이 아니라 식별 수단이라 유지됩니다

## 구조

```
src/core/    게임 규칙. DOM·React·canvas·시계·난수에 의존하지 않는 순수 로직 + 테스트
src/shell/   canvas 렌더 · 입력(DAS/ARR) · 고정 타임스텝 루프 · WebAudio
```

코어는 시간을 주입받고 난수는 시드 결정론입니다. 그래서 브라우저 없이 테스트가 돕니다.
